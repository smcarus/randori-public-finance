# Model cards

One page per model: what it is for, how it works, what it reads, how it was checked, and what it must not be used
for. Cite the model ID and version with any result. RPF stands for Randori Public Finance; each ID is
entered in Randori's Model Inventory.

| ID | Model | Status |
| --- | --- | --- |
| [RPF-01 v0.5](RPF-01.md) | Sovereign risk scorecard and decision tools | Port of the Randori workbook; untested, preliminary |
| [RPF-02 v0.1](RPF-02.md) | PPP fiscal risk, PFRAM 2.0 port | Matches the workbook; untested on a real project |
| [RPF-03 v0.2](RPF-03.md) | Municipal credit scorecard | Illustrative towns only; untested |
| [RPF-04 v0.1](RPF-04.md) | Debt sustainability: MAC SRDSF and LIC DSF ports | Matches both templates; untested on a new country |
| [RPF-05 v0.1](RPF-05.md) | Macro early-warning panel | No country data yet; untested |
| [RPF-06 v0.1](RPF-06.md) | Spillover network | No country data yet; draft elasticities; untested |

Every card has the same sections: purpose, method, inputs, outputs, validation, limits, use, and change log.
